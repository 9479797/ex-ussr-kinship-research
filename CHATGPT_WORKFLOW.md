# Работа с навыком через ChatGPT и GitHub

Этот репозиторий — **источник методики и инструментов**, а не хранилище личных генеалогических дел. Его можно использовать из ChatGPT с подключённым GitHub без отдельной установки на Mac. При работе в терминале локальный клон удобен для запуска скриптов, обращения к файлам и автономного использования; GitHub не запускает скрипты самостоятельно.

## Как использовать из ChatGPT

1. Назовите исследовательскую задачу и укажите, что следует использовать навык из `9479797/ex-ussr-kinship-research`.
2. Ассистент открывает актуальный [SKILL.md](SKILL.md), затем только относящиеся к задаче справочники `references/` и, когда нужно, шаблоны `assets/` или скрипты `scripts/`.
3. Генеалогические выводы строятся по проверяемым источникам, с раздельным учётом фактов, гипотез и противоречий; существенные находки связываются с происхождением документа и независимыми свидетельствами.
4. Для анализа **локальных** личных документов и сканов их необходимо предоставить в текущую работу через доступный файл или подключённое хранилище. GitHub-коннектор не даёт ассистенту прямого доступа к произвольным папкам Mac.
5. Изменение методики и репозитория выполнять адресно и только по текущей задаче. Сохранение отдельного дела и подготовка публичной версии исследования — разные действия.

## Разделение проектов

- `ex-ussr-kinship-research` — семейно-исторические источники и доказательство родственных связей.
- `9479797/historian-research` — общий исторический анализ, критика источников, сравнение объяснений.
- **Личное дело, изображения, переписка и реестры семьи** остаются в выбранном приватном хранилище; их нельзя автоматически переносить в этот публичный репозиторий.

Папка `skills/historian/` и `skills/historian-analyst/` здесь сохранена как ранее добавленные версии. Для дальнейшего развития исторических методик предпочтителен самостоятельный репозиторий `historian-research`, где есть более актуальные адаптации. Не считать одноимённые файлы в двух репозиториях автоматически синхронизированными.

## Обновления исходного навыка

Оригинал: https://github.com/DenisSergeevitch/ex-ussr-kinship-research

При новых выпусках сравнивайте изменения исходного проекта с текущей версией форка, отдельно сохраняя приватностные исключения `.gitignore` и авторские добавления. Перед значительными обновлениями создавайте контрольную ветку. Не переносите исходные документы дел в публичный GitHub.

**Примечание:** инструкции репозитория не подключаются к каждому диалогу ChatGPT автоматически. Их необходимо явно открыть при выполнении соответствующей задачи.
